从论文到推文，四步完成
  1. 导入论文。输入 arXiv 链接或上传 PDF，等待文字与原图提取。
  2. 确认配图。在“原文与配图”检查裁剪区域、图号与表格，勾选写作时使用的图片。
  3. 生成与编辑。配置模型，选择侧重点和篇幅，生成后逐章调整文字并保存。没有 API 也能导出提示词、导入 JSON。
  4. 自动投递。点击“自动整理并投递草稿”，软件将适配摘要、选择 overview 封面、检查素材并上传。人工审核仍可选，公开发布在微信后台完成。
自动检查后可提交公众号草稿；公开发表与群发在微信后台完成。模型生成与作者观点均需人工复核；软件、源码和数据独立于 GitHub 仓库，均保存在本机。导入 arXiv 会联网下载论文；生成时会连接你指定的模型服务。


RESEARCH RADAR
自动选题与投递


先看标题与链接，再选论文。列表检索只读 arXiv 元数据，不下载 PDF、不调用写作模型。所选论文逐篇完成图文与草稿投递，下一篇才会开始下载。






此处只筛选列表，不修改每日选题范围。交叉论文可出现在多个类别中。




每次可选 1–5 篇；使用当前模型与公众号，新稿采用自适应写作与排版、文本分析加原图配图。当前网络请求结束后响应停止，后续 PDF 不会提前下载。编辑作品前请先停止队列。




每日自动选题设置（独立于上面的手动选题）






优先级结合方向匹配、摘要中的方法/评测信息、代码线索和明确的作者机构。机构缺失不会排除；提到知名模型不等于作者来自该机构。此排序不是科学质量评分。




每天 09:00（北京时间）由 Codex 本地自动任务触发；电脑需开机且 Codex 可运行。无人值守每天最多 5 次生成尝试，无新论文则跳过。先刷新标题，只有轮到当前篇才下载 PDF；完成一篇再开始下一篇。无人值守仍核实项目和公开实现；失败保留进度并停止本轮。手动入口继续保留；手动选择不计此无人值守额度。




待处理文章可以打开后手动编辑、补图、审核并提交。自动检查不能证明事实、裁剪完整性或转载权限；请在发布前核对。模型与公众号密钥只从本机加密配置读取。
